 💐 Teachers' Day Interactive Message Card

An interactive, 3D animated greeting card built using **HTML5**, **CSS3**, and **JavaScript** to celebrate Teachers' Day. This project features a 3D book page-flipping effect, interactive confetti celebrations, custom audio feedback, and modern visual styling dedicated to Sir Randy Bello.


✨ Features

- **3D Page-Flipping Animation**: Realistic card-opening effect powered by CSS 3D transforms (`perspective`, `transform-style`, and `rotateY`).
- **Personalized Cover Design**: Custom image frame showcasing `Randy.png` along with tailored greeting text.
- **Interactive Confetti Blast**: Triggerable particle confetti canon built with `canvas-confetti`.
- **Audio Feedback**: Realistic page flip sound generated dynamically using the Web Audio API without relying on external audio assets.
- **Floating Particles**: Animated background sparkles for an engaging aesthetic.
- **Clean Code Architecture**: Fully modularized code separated into `index.html`, `style.css`, and `script.js`.
